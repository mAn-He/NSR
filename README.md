# Bike apparel 16-Week Demand Forecast

## Overview

This project aims to predict the 16-week sales demand for  a bicycle apparel company. The forecast is generated by a sophisticated multi-modal deep learning model that leverages a variety of data sources, including product images, textual descriptions, and structured metadata (such as color and category information). This approach allows the model to capture complex patterns and relationships between product attributes and sales performance.

## Key Features

*   **Multi-Modal Architecture:** The model fuses information from three different data types (images, text, and tabular data) to make more accurate predictions.
*   **State-of-the-Art Image Analysis:** Utilizes a pre-trained ResNet-152 model (via transfer learning) to extract rich visual features from product images.
*   **Advanced Text Processing:** Employs embeddings to represent textual features, allowing the model to understand nuances in product descriptions.
*   **Flexible Prediction Head:** The architecture supports multiple head configurations for the final prediction, including a standard MLP (`FFN`), a dense block, and a Transformer-based model for capturing sequential or relational information within the fused embeddings.
*   **Robust Target Engineering:** Applies a Box-Cox transformation to the sales data to stabilize variance and create a more Gaussian distribution for the target variable, improving model training and performance.
*   **Comprehensive Evaluation:** The model is evaluated using Mean Squared Error (MSE) for loss calculation and a custom Adjusted Symmetric Mean Absolute Percentage Error (Adjusted SMAPE) to measure forecast accuracy.

## Data Pipeline

1.  **Data Ingestion:** Sales and product data are read from CSV files.
2.  **Feature Engineering:**
    *   Relevant columns for training are selected.
    *   Textual data is converted into numerical embeddings.
    *   Image paths are prepared for the data loader.
3.  **Target Transformation:** The `판매수량` (sales quantity) target variable is transformed using a Box-Cox method followed by a linear scaling to normalize its distribution.
4.  **Dataset Creation:** A custom PyTorch `Dataset` (`img_txt_dataset`) is used to load images, text embeddings, and other features for each data point.
5.  **Data Loading:** Standard PyTorch `DataLoader` objects are used to feed data to the model in batches.

## How to Run

The model can be trained using the `train8_hs_knn_trial.py` script. The script is highly configurable through command-line arguments.

### Training

To train the model, run the following command from the root directory. You can customize the parameters as needed.

```bash
python train8_hs_knn_trial.py \\
    --device 0 \\
    --batch_size 32 \\
    --header_mode FFN \\
    --header_hidden_dims 256 128 \\
    --image_embeddings_dim_out 128 \\
    --text_embeddings_dim_out 128 \\
    --learning_rate 0.001 \\
    --num_epochs 100 \\
    --dir_path "experiments/ffn_model_01" \\
    --train_dataset "dataset/train.csv" \\
    --test_dataset "dataset/test.csv"
```

### Inference

The training script automatically runs inference on the test set using the best model saved during training. Prediction results and evaluation scores are saved to the directory specified by `--dir_path`.

## Model Performance

The model's performance is tracked and evaluated meticulously:
*   **Loss Function:** Mean Squared Error (MSE) is used to optimize the model during training.
*   **Evaluation Metric:** Adjusted SMAPE is used to provide an intuitive measure of forecast accuracy.
*   **Logging:** The training script saves detailed loss and evaluation metrics to a text file, including scores broken down by product category.
*   **Visualization:** Plots for training and validation loss/evaluation scores are generated and saved, allowing for easy visualization of the model's learning progress.
